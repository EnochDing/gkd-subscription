## 📱 订阅链接（复制到 GKD）

**raw 直链**（推荐首选）：

```
https://raw.githubusercontent.com/EnochDing/gkd-subscription/main/gkd.json5
```

**jsdelivr 加速**（raw 下不动时用这个，国内更快）：

```
https://cdn.jsdelivr.net/gh/EnochDing/gkd-subscription@main/gkd.json5
```

## 使用

1. 打开 GKD App
2. 首页 → 订阅 → 右上角 ➕
3. 粘贴上面任一地址，添加远程订阅
